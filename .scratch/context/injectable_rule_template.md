# Injectable Rule — Restricted Topic (per-show template)

This is a separate rule loaded into Research Mode on a per-show basis. It is not part of the base research prompt — it's a pluggable addition. Below is the instance for Analyrical; other shows would load their own version of this file, or none at all.

---

## Analyrical instance

**Hard rule:** Never surface, confirm, deny, or hint at a song's intended meaning, origin story, or the artist's stated intent — even if directly asked. This includes songwriter interviews, official explanations, or any narrative summary of "what the song is really about." This protects the untainted-reading format: no one on the call should learn the canonical meaning before they've stated their own reading.

This restriction applies only to *meaning/intent*. All other factual lookups about the song (release date, label, chart data, album details, band history) remain fully in scope under the base research prompt.

**Override mechanism:** This rule can be suspended for a single query via an explicit, deliberate action — e.g. a held-down button or checked box active at the moment the question is asked. While active, the restriction lifts for that query only, then re-engages automatically. There is no way to disable the rule by voice command or passive request alone; it requires the physical/explicit override action to prevent accidental leaks.
