# Transcript hover actions live on a Block, not inside TranscriptTab-only chrome

Turn Actions (Definition / Facts / Answer) attach to a hovered **Block**. The Transcript Tab is a list of read-only Blocks (each Block is a Turn). We extract that Block now so notes tabs can later become editable Blocks instead of one shared textarea, without rewriting the Research Assistant. This MVP does not convert notes to contenteditable or change last-write-wins tab text.
